1. Description

The Web to Markdown API converts web pages and raw HTML into Markdown. It is operated at thenapply.dev, and its endpoints, documentation, and dashboards form part of the Service as described in the Terms.

2. Content

For this Product, Content takes the following form:

  • Input — a URL, or raw HTML, together with any conversion parameters the Customer supplies.
  • Output — Markdown, extracted metadata, and error payloads.

4. Output quality

The Provider does not warrant that Markdown output will be accurate or complete for every page converted: conversion quality depends on the structure of the source page being fetched, which the Provider does not control.
