Este Anexo es específico del Producto Web to Markdown API (el «Producto») y se incorpora por referencia a los Términos de Servicio (los «Términos»). Los términos en mayúscula no definidos aquí tienen el significado que les dan los Términos, que prevalecen en cualquier materia que este Anexo no regule.

1. Descripción

La API Web to Markdown convierte páginas web y HTML en crudo a Markdown. Se opera en thenapply.dev, y sus endpoints, documentación y paneles forman parte del Servicio tal como lo describen los Términos.

2. Contenido

Para este Producto, el Contenido tiene la siguiente forma:

  • Entrada — una URL, o HTML en crudo, junto con los parámetros de conversión que indique el Cliente.
  • Salida — Markdown, metadatos extraídos y cuerpos de error.

Este Producto convierte el Contenido que el Cliente le indica que descargue, o que el propio Cliente le envía. Las consecuencias de ello en materia de responsabilidad se establecen en la sección 9.2 de los Términos, que se aplica sin cambios a este Producto.

3. Propiedad intelectual

El nombre y la marca Web to Markdown forman parte de la propiedad del Proveedor, tal como describe la sección 5.1 de los Términos.

Cuando ciertos componentes de este Producto se distribuyan por separado bajo una licencia de código abierto, esa licencia es la que rige el paquete npm web-to-markdown. Rige esos componentes únicamente en su forma distribuida, y no otorga derecho alguno sobre el Producto alojado, su infraestructura o las marcas.

4. Calidad de la salida

El Proveedor no garantiza que la salida Markdown sea exacta o completa para toda página convertida: la calidad de la conversión depende de la estructura de la página de origen, que el Proveedor no controla. Esto describe lo que el Producto hace; no es una renuncia a la obligación del Proveedor de prestarlo.

Nada en esta sección excluye ni limita derecho o remedio alguno que la ley imperativa aplicable reconozca a los consumidores, ni los remedios legales preservados en la sección 9.1 de los Términos, ni los requisitos de conformidad preservados en la sección 8.3 de los Términos. Como establece la sección 1.1 de los Términos, nada en este Anexo puede reducir una salvaguarda que los Términos reconozcan al Cliente.
