## 1. Description

The Web to Markdown API converts web pages and raw HTML into Markdown. It is
operated at `thenapply.dev`, and its endpoints, documentation, and dashboards
form part of the Service as described in the Terms.

## 2. Content

For this Product, Content takes the following form:

- **Input** — a URL, or raw HTML, together with any conversion parameters the

- **Output** — Markdown, extracted metadata, and error payloads.

This Product converts Content that the Customer directs it to fetch, or that
the Customer submits directly. The consequences of that for liability are set
